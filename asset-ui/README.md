# Asset Management UI (Angular 19)

Requires Node 20+ (or 18.19+) and the backend running on http://localhost:8080.

    npm install
    npm start

Open http://localhost:4200 (use "localhost", not 127.0.0.1 - the backend CORS allows that origin).
Backend URL is set in src/app/core/config.ts.
